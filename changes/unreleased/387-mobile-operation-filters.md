# Tri et filtres des opérations sur mobile

Les opérations ponctuelles et le budget fixe disposent d’un panneau de tri et de filtres tactiles, avec suggestions ou texte libre pour le libellé, critères résumés et effaçables, et annonces accessibles. Les opérations ponctuelles sont filtrées par le serveur ; les fixes utilisent les mêmes règles locales que le Web sur leur collection complète.
