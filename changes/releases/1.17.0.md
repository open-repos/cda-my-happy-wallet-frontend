### Web

- Comparez votre reste à vivre actualisé à votre montant théorique sur l’accueil et dans le calendrier, avec un détail accessible du calcul.

### Évolutions mobiles intégrées

Les nouveautés ci-dessous sont intégrées au code mobile. Leur disponibilité sur Android et iOS dépend d’une livraison mobile distincte de cette release Web.

- Consultez le reste à vivre de chaque jour dans le calendrier prévisionnel, avec les sept jours visibles et les montants exacts accessibles dans le détail.
- Comparez trois trajectoires d’épargne pour un objectif : rythme prévu, maximum théorique et estimation raisonnable.
- Consultez vos enveloppes budgétaires, déclarez une charge mensuelle comme enveloppe et rattachez vos dépenses à l’enveloppe du mois.
- Retrouvez les catégories de vos charges et revenus fixes, et triez ou filtrez vos listes d’opérations.
- Ouvrez les liens de confirmation d’inscription et de réinitialisation du mot de passe dans l’application. Un message rappelle de vérifier les courriers indésirables après une demande d’email.
- Accédez aux derniers éléments des écrans sans qu’ils soient masqués par le bouton d’ajout.
